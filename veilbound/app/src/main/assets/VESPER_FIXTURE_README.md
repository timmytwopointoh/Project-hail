# Vesper GLB parser smoke fixture

The companion binary asset `vesper_import_smoke.glb` is a synthetic two-joint red triangle with rotating tip animations, generated exclusively for Android GLB import regression tests. It is **not** the full Vesper character, not reference likeness evidence, and not permission to ship the synthetic character as a game asset. Real Vesper must be imported from the user-reviewed GLB using the Model Atelier.
