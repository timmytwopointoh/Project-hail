# M23 extreme refinement — bounded execution manifest
Base: M22 hand-knuckle contours. Do not touch hair. Preserve armored playable game.
Duration: maximum 60 minutes per explicitly triggered run. No unattended continuous loops.
Manager lanes: hands; head/face; upper torso; pelvis/legs/feet; skin/material; rig/deformation; Android 15 visual QA; integration/learning.
Candidate budget: 50 total slots, not 50 presumed active agents. Each candidate must contain source diff, affected bones/meshes, 14-angle render references, defect checks, and human-readable rationale.
Mandatory acceptance: each hand exactly four separately meshed fingers plus one anatomically opposable thumb, with clear gaps and natural knuckle joints; inspect front, side and three-quarter. Manually review topology, silhouette, weights and moving poses. Never auto-promote numeric winner.
Validation: manifoldness, normals, winding, UVs, skin weights, mesh clipping, skeletal articulation, compatible Android 15 emulator images, four verified real screenshots if meaningful change, performance and armored game regression.
Learning journal per attempt: candidate id, baseline, hypothesis, modifications, visual evidence, pass/fail, human review, reusable lesson, next experiment.
Stop on missing visual evidence, failed regression, or unreviewed candidate. Do not claim completion based on tests alone.
